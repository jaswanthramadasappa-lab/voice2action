# Voice2Action AI

Turn voice notes into organized summaries, decisions, and actionable tasks.

## Current version
Step 2: React UI + browser audio recording + audio upload.

## Run frontend
```bash
cd client
npm install
npm run dev
```
Frontend: http://localhost:5173

## Run backend
Open a second terminal:
```bash
cd server
npm install
npm start
```
Backend: http://localhost:5000
